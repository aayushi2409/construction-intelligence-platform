# Construction Intelligence Platform

A Streamlit-based construction intelligence dashboard for:

- PPE and site safety audits
- Concrete crack diagnostics
- Cost and valuation planning
- Site assistant guidance for civil engineering workflows

## Tech stack

- Python
- Streamlit
- Pillow
- Google Generative AI

## Run locally

```bash
cd "C:\Users\Lenovo\Downloads\files"
.\.venv\Scripts\streamlit.exe run app.py --server.address 0.0.0.0 --server.port 8502
```

## Notes

- The app can run in demo mode without a Gemini API key.
- A valid Google Gemini API key enables live AI analysis.
